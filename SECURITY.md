# Security

Wren Wallet holds people's money. Security reports are the most valuable
contribution you can make.

## Reporting a vulnerability

Please report privately through GitHub:
**Security tab → "Report a vulnerability"** on this repository.

Do not open a public issue for a security problem. We will reply, work on a
fix with you, and credit you (if you want) when the fix ships.

## Scope

In scope: the signing engine, key storage, app lock, the Claim flow,
wrong-chain and replay protections, server verification, and the build and
release process.

## Status

Wren Wallet is in design. No release exists yet. Any app or download that
claims to be Wren Wallet today is not ours.

Wren will never ask for your recovery phrase, by message, by email, or on any
website.
